# Saptaśatī Reader

Śrī Durgā Saptaśatī (Devī Māhātmyam) verse by verse: all 700 mantras and the Gita Press pūrvāṅga and uttarāṅga, in Telugu and Devanagari script with IAST, word-by-word meanings, English and Telugu explanations, story context, a guru/laghu pronunciation guide, a continuous paath mode and a practice mode. Works offline as an installable app on phone and iPad.

## Layout

| Path | What it is |
|---|---|
| `docs/` | The built website. GitHub Pages serves this folder. Do not edit by hand. |
| `site/index.html` | The app (HTML, CSS and JS in one file). |
| `site/data/text.json` | The full Sanskrit text, generated by `src/`. |
| `notes/` | Meanings, written by section. `notes/<section>.json` or `notes/parts/<section>.<part>.json`. |
| `src/` | Scripts that turn the source texts into `text.json`. |
| `build.py` | Validates the notes and builds `docs/`. |

## Adding meanings

Notes are keyed by the verse reference used in `text.json` (`"1.2"`, `"5.14-16"`, `"pre0"` for viniyoga/dhyāna blocks):

```json
{
  "_intro": {"en": "...", "te": "..."},
  "2.1": {
    "pada": [["word in IAST", "English gloss", "తెలుగు అర్థం"]],
    "en": "Meaning in English",
    "te": "తెలుగులో అర్థం",
    "ctx": {"en": "optional story context", "te": "..."}
  }
}
```

Then run `python3 build.py`. It reports unknown references or missing meanings, and rebuilds `docs/`.

## Rebuilding the text

```sh
sh src/fetch_sources.sh
cd src && python3 parse.py && python3 parse_extra.py && cd ..
python3 build.py
```

## Source and terms

The Sanskrit text comes from [sanskritdocuments.org](https://sanskritdocuments.org/doc_devii/durga700.html), prepared by volunteers for personal study and research and not for commercial use. The raw source files are not kept in this repository. A few source typos are corrected in an errata list in `src/parse.py`. Meanings and word notes are a study aid; check difficult passages with a teacher or a printed commentary.
